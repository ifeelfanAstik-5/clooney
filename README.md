API/Web Socket Interface
    Routes, request/response schema, validations, edge cases, business logic nuances like conditional data in the response for certain request parameters etc

Pixel perfect UI & UX
    Every single UI element along with how the UI behaves upon human interaction should be replicated.
    Your Agent should be able to iteratively work through each component/section and create a high fidelity replica of the desired web application
Data Schema
    As it is not possible to know the exact data schema, maintain the best possible parity based on your understanding of the API resources and Product documentation of the web app your agent will replicate.
